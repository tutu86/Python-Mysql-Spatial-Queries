# Python-Mysql-Spatial-Queries
spatial query with python

1) Read KML format polygons from local as a GeoPandas Dataframe
2) Connect to a mysql database and perform a query 
3) Transform mysql data to a GeoPandas Dataframe 
4) Perform a spatial query (point in polygon in this example) 
5) Visualise the results on basic Matplotlib 

for more documentation about Geopandas http://geopandas.org
